## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `.nojekyll` to the root of the repository.
3. Open the repository's **Settings**.
4. Open **Pages**.
5. Choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save and wait for GitHub Pages to publish the site.

The website is self-contained: the destination photos and official logo are embedded in `index.html`, so you do not need to upload a separate images folder.

## Custom domain
After the GitHub Pages site is working, you can connect `teddybearshuttle.com` from the GitHub Pages settings and update the domain's DNS records with your domain provider.
